# 🛒 Online Electronics Store

## 📌 Project Overview

Online Electronics Store is a web-based e-commerce application developed using Java and web technologies. It allows customers to browse electronic products, register, log in, and place orders.

The application uses JDBC for database connectivity and Oracle SQL for managing customer, product, and order information.

## 🚀 Technologies Used

- **Backend:** Core Java, JSP, Servlets
- **Database:** Oracle SQL
- **Database Connectivity:** JDBC
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Server:** Apache Tomcat
- **Architecture:** MVC (Model-View-Controller)

## ✨ Features

- Customer Registration
- Customer Login and Logout
- Product Browsing
- Product Management
- Shopping and Order Management
- Customer Account Management
- Database Operations using JDBC
- Session Management

## 🏗️ Project Architecture

The application follows an MVC-based architecture.

```text
        User
         |
         v
      JSP Pages
         |
         v
      Servlets
         |
         v
      DAO Classes
         |
         v
        JDBC
         |
         v
    Oracle Database
```

## 📂 Project Modules

1. Customer Module
2. Product Module
3. Shopping Module
4. Order Management Module
5. Database Connectivity Module

## ⚙️ Installation and Setup

1. Clone this repository.

   ```bash
   git clone https://github.com/Nikhil-JFS-Git/Online-Electronics-Store.git
   ```

2. Import the project into Eclipse.

3. Configure Apache Tomcat Server.

4. Configure Oracle Database connectivity.

5. Update database connection properties according to your local environment.

6. Run the project on the Tomcat server.

7. Open the application in your browser.
